# London House Prices and Neighbourhood Characteristics

This project explores how crime, deprivation and public transport accessibility are associated with median house prices across London neighbourhoods at LSOA level.

The project combines data from:

- Office for National Statistics (ONS) – house prices
- Metropolitan Police Service – crime
- English Indices of Deprivation – deprivation measures
- Transport for London – public transport accessibility

## Repository Structure

- `data_preparation.ipynb` – data loading, cleaning, geographic reconciliation and merging
- `data/london_house_price_data.csv` – cleaned dataset prepared for analysis
- `requirements.txt` – Python dependencies
